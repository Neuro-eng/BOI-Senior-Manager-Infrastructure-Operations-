# BOI Senior Manager (Infrastructure Operations) Exam Prep

A single-page study kit: 30-day plan, notes, cheat sheet, 125-question practice quiz,
interview Q&A, English and banking awareness, and source links.

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example `boi-infra-ops-prep`).
2. Upload everything in this folder, including the hidden `.github` folder, to the `main` branch.
3. In the repository go to Settings > Pages and set Source to "GitHub Actions".
4. Open the Actions tab; the "Deploy to GitHub Pages" run publishes the site.
5. Your site: https://YOUR-USERNAME.github.io/REPO-NAME/

## Updating the material
Edit `index.html` (add questions in the `A(...)` list, update the dates) and commit to `main`.
The workflow redeploys automatically within a minute or two, and the page's Refresh button loads the newest version.
Always confirm dates and eligibility in the official Bank of India notification.
